# Feedback

This repository takes feedback through **issues only**. Pull requests are switched off.

Use an issue for:

- a bug in the listing page or in a skill text
- a request for a new one-chat skill
- a question about how a skill is meant to be used

Please pick the matching template, say whether you use Claude on the web, desktop, or mobile, and never paste passwords, keys, or private data into an issue. Requests are read and, where they fit, built by the maintainer.
